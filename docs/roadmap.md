# 开发计划

## 1. 明确方向

- [ ] 确定游戏类型、目标平台和核心玩法
- [ ] 选择引擎与版本
- [ ] 写清首个原型的范围

## 2. 做出可玩原型

- [ ] 创建引擎工程，补充对应的忽略规则
- [ ] 实现核心操作
- [ ] 跑通开始、游玩、结束和重开的完整流程
- [ ] 自己试玩并记录问题

## 3. 根据试玩完善

- [ ] 邀请少量玩家试玩，记录反馈
- [ ] 优先修复影响游玩的缺陷
- [ ] 补充必要的美术、音效和界面
- [ ] 在 README 中加入真实截图和运行说明

## 4. 准备发布

- [ ] 核对素材来源与授权
- [ ] 在目标设备上验证安装和运行
- [ ] 根据届时 TapTap 的要求准备页面、安装包与发布资料

随项目进展调整计划；只有实际完成的任务才勾选。
