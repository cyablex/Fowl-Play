# 首个可玩原型任务书

目标：先做一只鸡的训练场，再扩展成两分钟内可结束并重开的鸡对鸡人机游戏。本文件是下一步实现规格，所有任务目前尚未开始。

## 1. 最小范围

| 训练场 M1 必须有 | 完整原型 M2 再加入 | 更后面再做 |
| --- | --- | --- |
| 一只鸡的占位图与移动 | 一个机器人对手 | 猪、马及其技能 |
| 脚底碰撞与遮挡 | 计时、计分、死亡、复活 | 真人联网房间 |
| 飞羽普攻和可受伤木桩 | 干草堆和玉米 | 排位、成长、商业化 |
| 一个增速技能与冷却显示 | 开始、结算和重开 | 完整美术与所有方向动画 |
| 左摇杆、右侧按钮与键鼠 | 人机对局选择入口 | 第二技能或拖拽瞄准 |
| 围栏、相机和手机验证 | 完整 Android 可玩包 | 多张地图与复杂视野 |

## 2. 初始调试参数

这些数值只用于建立第一轮手感，没有经过平衡验证；放在配置中，避免散落在脚本里。单位为统一 2D 游戏单位，可暂按参考像素理解，不随手机物理分辨率变化。

| 项目 | 起点 |
| --- | --- |
| UI 参考画布 | 1280×720，横屏，战斗视野范围统一 |
| 测试地图 | 约 1600×1100，两个出生区、中央掩体、侧面绕行路 |
| 鸡生命 | 100 |
| 鸡移速 | 220 单位／秒 |
| 飞羽伤害 | 15 |
| 攻击间隔 | 0.4 秒，从成功生效开始计算 |
| 飞羽射程／速度 | 384 单位／680 单位每秒 |
| 普攻前摇／后摇 | 0.08 秒／0.12 秒；允许移动 |
| 扑腾疾跑 | 移速 ×1.5，持续 1.5 秒，冷却 6 秒；立即生效 |
| 干草堆生命 | 45，破坏后本局不再生成 |
| 玉米 | 受伤才可拾取，回复 25，不超过最大生命；拾取后 15 秒刷新 |
| 对局 | 倒计时 3 秒，最长 120 秒，先 5 分结束 |
| 复活／保护 | 3 秒／1 秒；主动攻击或放技能提前结束保护 |

不因为调试参数写在文档里就批量制作最终资源。先用基础几何图形或少量占位图完成逻辑，并记录素材来源。

## 4. 第一批场景和素材

场景最先只创建启动入口、训练场、共享角色、木桩、飞羽、触屏控件。菜单与结算等到对局循环出现再创建。

最小素材：鸡的左右朝向占位图、圆形阴影、飞羽图、地面块、围栏、干草堆、玉米、按钮图形和可用中文字体。鸡可先翻转实现左右方向；受击闪白与简单缩放可以暂代复杂动画。音效先补命中、发射、技能和结算几类，正式导入时登记授权。

## 5. 手工验收清单

### 训练场

- [ ] 从围栏后方绕到前方，遮挡随脚底位置正确变化。
- [ ] 角色贴图向上延伸，但身体不会被顶部透明区域挡住。
- [ ] 斜向移动与水平移动速度相同；摇杆死区不会让角色缓慢漂移。
- [ ] 左指持续移动时右指连续点普攻；右指离开后左指仍有效。
- [ ] 切后台再返回，角色不会持续移动或自动连发。
- [ ] 左右移动时仍能朝同一个敌人射击，不强制只沿移动方向攻击。
- [ ] 敌人在墙后、射程外或已死亡时不被辅助瞄准选中。
- [ ] 飞羽撞围栏就消失，不在同一帧穿过围栏击中后面的敌人。
- [ ] 高速弹体与薄障碍场景没有穿透；一个弹体不会多次扣血。
- [ ] 疾跑能边移动边用；重复点按不刷新持续时间或绕过冷却。
- [ ] 不同宽高比手机保持统一战斗视野，按钮位于可触达的安全区。

### 完整人机对局

- [ ] 倒计时结束前不能造成有效伤害；进入 Playing 后才计时和计分。
- [ ] 致死、复活、保护取消与 5 分结束符合规则。
- [ ] 机器人不会直穿围栏，也不会隔墙锁定目标攻击。
- [ ] 玉米在满血时不消耗；受伤拾取后按约定刷新。
- [ ] 干草堆破坏后立即移除对应碰撞，重开时恢复。
- [ ] 时限到后同分能显示平局；结束后弹体不继续加分。
- [ ] 重开后生命、分数、冷却、弹体、状态、计时器和地图均重置。
- [ ] 连续 10 局无阻止结束／重开的错误，Android 上完成同样流程。

## 6. 记录试玩

每条问题记录：构建版本、设备与系统、复现步骤、预期、实际、截图／视频、严重程度。优先修复无法进局、误触、卡住、错误命中与重开残留，再调伤害和移速。

M2 完成后产物：可玩 Android 包、Windows 开发运行说明、至少一段实机操作视频、问题列表，以及是否继续采用点按瞄准与当前规则的结论。不要把人机原型包装成已经完成真人联网的版本。
