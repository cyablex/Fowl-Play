# Fowl Play

一个计划上架 TapTap 的小游戏。本仓库记录项目的代码、设计和开发过程。

## 当前状态

项目初始化阶段，尚无可玩版本。游戏类型、核心玩法、引擎和发布平台待确定。

## 第一个目标

做出一个能体验完整核心玩法的小原型，再根据试玩反馈决定后续内容。

## 仓库内容

| 文件 / 目录 | 用途 |
| --- | --- |
| `README.md` | 项目介绍、当前状态和启动说明 |
| `docs/game-design.md` | 玩法构想和第一个原型的范围 |
| `docs/roadmap.md` | 下一步任务和阶段目标 |
| `docs/devlog.md` | 实际完成的工作和开发记录 |
| `docs/asset-sources.md` | 外部素材的来源、授权和使用位置 |
| `.gitignore` | 排除临时文件、密钥和本地配置 |

选定引擎后，将引擎项目加入仓库，并补充代码、场景和素材目录以及运行方法。目录结构遵循所选引擎的习惯。
