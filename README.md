# Fowl Play

一款计划在 TapTap 发布的农场动物对战小游戏，使用 Godot 制作。玩家操控鸡、猪、马等动物，通过走位、各具特色的普攻与技能，以及农场中的道具展开短局对战。

## 当前状态

**目前已完成第一版设计与开发规划，尚未创建 Godot 工程，没有可运行的游戏。** 文档中的目录、模块、动物能力和阶段目标均为实现方案，不能视为已实现功能。

- 已确定：Godot、纯 2D 角色与场景、模拟 2.5D 俯视纵深、左摇杆移动、右侧点按技能、农场动物对战、目标渠道 TapTap。
- 建议默认：Android 横屏优先、GDScript、先做一只鸡的人机原型，再验证联网，逐步扩充到三只动物。
- 待细化：具体美术风格、正式对战人数与模式、第二个技能槽、商业化、开发投入和目标设备。详见 [决策记录](docs/decisions.md)。

## 从这里开始

1. 阅读 [玩法框架](docs/game-design.md)，了解操作、动物定位、地图道具和首版范围。
2. 按 [开发路线图](docs/roadmap.md) 的 M0 → M1 → M2 顺序推进，先完成一局人机对战。
3. 开始编程时使用 [Godot 技术架构](docs/architecture.md) 和 [首个原型任务书](docs/first-prototype.md)。
4. 在公开测试前完成 [TapTap 发布准备](docs/taptap-release.md) 中对应阶段的事项。

## 第一个可玩目标

**一只鸡、一张小农场、一个机器人对手、一种普攻、一个主动技能，两分钟内完成一局并可以重开。**

先在训练场验证移动与攻击手感，再接入人机规则。基础地形使用围栏；可破坏干草堆和玉米回血作为完整人机原型的两种交互。初期用占位图即可。

```mermaid
flowchart LR
    M0[确定原型规格] --> M1[移动与攻击训练场]
    M1 --> M2[完整人机对局]
    M2 --> M3[双客户端联网验证]
    M3 --> M4[三只动物与农场交互]
    M4 --> M5[小规模在线测试]
    M5 --> M6[TapTap 测试与发布]
```

## 如何运行

当前无法运行。下一阶段计划在 `game/` 中创建 Godot 项目，并记录实际使用的 Godot 完整版本、导出模板版本和运行方法；目前 `game/project.godot` 尚不存在。

开发阶段保留 Windows 键鼠操作便于调试，触屏多指操作和 Android 真机验证从首个训练场阶段开始。
